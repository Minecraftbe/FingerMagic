# FingerMagic

用摄像头或视频里的单只手触发实时视觉特效。项目使用 OpenCV 的肤色、运动和轮廓分析来定位手部，再将效果贴合到实际手部轮廓，而非仅用几个指尖连成一个大框。

## 已改进的体验

- 手部静止时仍会短暂保持追踪，不会因背景建模完成而立即丢失效果。
- 采用完整手部轮廓和柔边遮罩，手指间的空隙不会被粗暴填满。
- 新版星空、虹彩、霓虹、传送门和指尖火花均带有柔光、动画和分层混合。
- 默认画面不再覆盖调试用的绿点与连线；需要时可按 `d` 查看检测轮廓。

## 运行

先准备好项目虚拟环境与依赖，然后双击 `run.bat`，或在终端中运行：

```bat
run.bat --effect starfield
```

可选效果：`starfield`、`rainbow`、`particle`、`neon`、`portal`、`all`。

处理本地视频并保存结果：

```bat
run.bat --input input.mp4 --effect portal --output output
```

## 操作

- `1`–`5`：切换特效
- `a`：叠加全部特效
- `d`：显示/隐藏检测轮廓与指尖标记
- 空格：暂停
- `q`：退出

启动后的约一秒用于建立背景模型。请先让手进入镜头并轻微移动一下，以便完成初次识别；之后可以保持相对静止。
